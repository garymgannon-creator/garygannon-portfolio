How to Use This Prototype

Purpose: To demonstrate, on fictional data, how an employer or property operator could record the shared zones of a multi-employer property, who uses and maintains each zone and when, which facts are still unknown, and what follow-up questions and specialist referrals those gaps raise, for human review.

  • Select a Fictional Property Archetype (A, B, C, or D): Use the selector at the top to switch between four illustrative property configurations.
  • Review Computed Metrics (Module 1): Summary counts are calculated automatically from the active dataset. Review the Draft Template Notes showing items marked Template placeholder: pending operator input.
  • Explore Zones & Shared Use (Modules 2, 3, 4, 7): Filter zones, click any row in the Zone Register to inspect details, view the abstract zone schematic grouped by band, or inspect 24-hour vendor/employer overlap windows (including windows crossing midnight).
  • Test Control Facts & Rule-Based Routing (Module 5): Change any zone's five control facts (F1 through F5) or evidence labels to see rule-based follow-up questions and specialist flags update dynamically.
  • Manage Actions & Walk Logs (Modules 9, 10, 11): Add or update follow-up actions and readiness walk observations in memory. Export any table's current filtered view to CSV or use Print / Save as PDF.
